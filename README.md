# 跨境企业撮合履约

支持跨境企业从会前配对、现场洽谈到会后合作落地。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括峰会秘书处、境内企业、东盟企业、专业服务机构。

资料所依据的领域事实如下：

- 会前通过系统预配对大量供需信息
- 现场设置多个行业对接会和一对一洽谈区
- 会后线索将沉淀并继续提供全年服务

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
